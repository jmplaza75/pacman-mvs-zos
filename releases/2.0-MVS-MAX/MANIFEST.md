## Reproduce from empty libraries
```sh
python3 tools/make_deck.py ALLOC --prefix HLQ.NAME && python3 tools/run_deck.py build/ALLOC.jcl
./tools/release_check.sh 2.0 HLQ.NAME        # REL20 + run-only S2 / RP / GP2 / GP23 / HS + tests/test_g8.py
python3 tools/make_deck.py CLIST --prefix HLQ.NAME && python3 tools/run_deck.py build/CLIST.jcl
```
To install a validated build into another prefix without relinking: `make_deck.py INST20 --source HLQ.NAME --prefix TARGET`.
