# G3 idle tick: diagnosis so far (2026-10-08)
Live RECTRACE (CLIST METRICS(YES), JOB 174 build, ~10 s untouched then Q): `RECTRACE EMPTY=0021 DATA=0001 ERR=0000 LASTRC=0000 TICKS=0021 SENPRC=0000`.
=> RECT (TGET ASIS,NOWAIT) returns RC 4 every 0.5 s from the start (not blocking); 21 tick streams were sent with SENP, all TPUT RC 0;
nevertheless C/O and G/W did not alternate on screen until after the first logical command.
Data check (real COBOL streams of TSD run TICKS, JOB 174 = identical to the independent model), both 35 bytes:
 first tick after the initial FULLSCR : C2 | 11 C5 5F  28 42 F6 28 41 F2 D6 | ... W cells ... | 28 00 00   (SBA, SA yellow, SA reverse, 'O' (Pac-Man), ghosts 'W')
 first tick after the first R move    : C2 | 11 C5 60  28 42 F6 28 41 F2 D6 | ... W cells ... | 28 00 00   (same shape, other cell)
The shadow image is synchronised after the initial full screen (KEEP-VS after COMPOSE, PREV-OK=1); the stream is non-empty and correct.
So the cause is not the renderer state: the writes are issued (RC 0) but not displayed (or not applied) before the first AID has been read.

## Experiments T1-T3 (live)
Start: no alternation. T1 empty ENTER: nothing. T2 `X`+ENTER: INVALID COMMAND shown, still no alternation. T3 PA2: alternation starts at once.
Program-level sequence of ENTER-empty and PA2 is identical (RDR -> STAT -> PRMT -> full screen -> TPUT FULLSCR); only the inbound AID differs
(7D vs 6E): the PA2-specific action is TSO's reshow-key handling, not ours. Open puzzle: in an earlier run the first R also started the ticks, X did not.
## Probe E7 (JOB 176, src/probe/PACFS7.asm generated by tools/gen_probe_e7.py, CLIST E7PROBE)
Same startup as the game + the model's initial screen and the two tick streams, 30 ticks 0.5 s apart; variants A (no TGET in loop), B (TGET NOWAIT),
C (B + WCC C3), D (B + STFSMODE without INITIAL=YES). Run A first.
E7-A live (JOB 176): `G7P V=A RC1=0000 RC2=0000 TICKS=0090 PA2=0002 SCRNS=0003 AID=7D`: 90 ticks RC 0, NO alternation, not even after PA2 (twice),
no flicker. => TGET NOWAIT is not the cause, and PA2 alone does not enable the ticks.
## E6 (works) vs E7-A (fails), from the code of both probes
| Factor | E6 PACFS3 (partials visible) | E7-A PACFS7 = game (ticks not visible) |
|---|---|---|
| TCLEARQ / STFSMODE ON,INITIAL=YES / STTMPMD ON | same | same |
| Read Partition Query (TPUT NOEDIT WSF + TGET) | no | yes |
| Full screen | TPUT FULLSCR, WCC C3, unformatted (no SF), IC | TPUT FULLSCR, WCC C3 + clear prefix (SBA 1,1 + RA nulls), formatted (SF protected fields + 1-byte input field), IC |
| Time full screen -> first partial | 2 s (STIMER) | 0 s (first tick at once) |
| Partial WCC | C3 (reset MDT + restore) | C2 (restore only) |
| Partial structure | X'F1' + WCC + per cell SBA/SA colour/SA reverse/char/SA41 00, then 28 00 00 | X'F1' + WCC + SBA/SA colour/SA reverse/char, SBA/SA colour/char, 28 00 00 |
| TSO calls between full screen and first partial | STIMER only | none |
In the game, logical partials (WCC C3: moves, INVALID) were always visible; idle ticks (WCC C2) were not -> WCC is the only factor that also
separates visible from invisible partials inside the game itself.

## CORRECTION: all E7 results are invalid (probe bug, found 2026-10-08)
PACFS7 SENDTICK computed the TPUT length with `L 0,TLEN` + `LA 0,1(0)`: R0 as base register means 0, so every tick TPUT received length 1
(only the X'F1' command byte) - the same mistake as G1 JOBs 159/160. E7 A, K, T, D (and Q, P, F, I never run) say nothing about the
protocol. The game is not affected (PACFSIO SENP: `LH 0,0(4)` + `AH 0,=H'1'`). E7 is abandoned.

## Real game check in c3270's presentation space (user + sample_probe_cells.py, 2026-10-08) - CHANGES THE DIAGNOSIS
Pac-Man (5,32) and ghost (12,49) stay C/G the whole idle time, also while an R is typed (field = R, cursor 17 16, no logical move); a

## Fix (authorised): visual ticks with TPUT BREAKIN (JOB 183)

PACPLAT SEND-PART uses SENT only when DS-KIND = 'T', same error semantics (RC <> 0 -> REQ-SENDST R, REDRAW F, ANIM N). Logical partials
(SENP), full screens (SEND), WCC C2, TGET NOWAIT, STIMER, PACSCR and the core unchanged. Regression: 61 steps RC 0000, no warnings,
oracle identical, 199 TSC streams identical to the model (the data stream did not change), test_g2/g0/mvs8/core_frozen PASS.
