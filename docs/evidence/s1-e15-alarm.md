## Conclusions
- The WCC alarm bit (X'04') reaches c3270 unchanged through all three production send paths (TPUT NOEDIT Erase/Write,
  TPUT FULLSCR, TPUT NOEDIT Write) and is audible on the Mac (c3270 rings the terminal bell). TSO/VTAM do not strip it.
- The alarm is a WCC flag, so it costs no extra write: it can ride on a frame the game already sends.
- For a later MVS-S2 (not started): three bells were individually audible both when they arrived in one socket read
  within 1 ms and when spaced 0.5 s apart. Pitch and length cannot be controlled (one fixed terminal bell).
- Audibility depends on the client: the terminal's bell setting (macOS Terminal "Audible bell") and volume. This is
  the only client-side condition; nothing else runs off MVS.
